# Network Speed Test

A Python command-line tool that retrieves the public IP address and measures network performance.

## Description

Network Speed Test is a simple Python project designed to measure the performance of an Internet connection.

The program retrieves the public IP address using the IPify API and then uses Speedtest to measure network performance.

The project was created as a learning project to practice Python, HTTP requests, APIs, exception handling and basic networking concepts.

## Features

- Public IP address detection
- Internet server connectivity check
- Ping measurement
- Download speed measurement
- Upload speed measurement
- Automatic selection of the best Speedtest server
- Basic connection error handling
- HTTP status code verification

## Technologies

- Python
- Requests
- Speedtest
- IPify API

## Requirements

Python 3 is required.
